# Tec-Commerce

A modern e-commerce website built using **Python Flask**.

## Features

- No Database Required
- JSON Product Storage
- Stylish Responsive Design
- Product Details
- Shopping Cart
- Checkout
- Search Products
- About Page
- Contact Page

## Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript
- Bootstrap 5

## Installation

Install Flask

```bash
pip install flask
```

Run the project

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
